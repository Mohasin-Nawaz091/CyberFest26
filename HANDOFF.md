# CyberFest 2026 handoff

## What is included
- React + Vite event website
- GSAP + ScrollTrigger animation system
- Lenis smooth scrolling
- Parallax hero image and background glow
- Animated reveal-on-scroll sections
- Counter animations
- Infinite sponsor marquee
- Magnetic buttons
- 3D hover tilt cards
- Interactive FAQ accordion
- Responsive mobile navigation
- CyberFest black + electric-lime visual language
- Reference screenshots included for comparison

## Start
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local Vite URL.
