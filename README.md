# CyberFest 2026 — Animated Event Website

A black + electric-lime event landing page inspired by the supplied reference screenshots, rebuilt from scratch with React, GSAP, ScrollTrigger and Lenis.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included
- Smooth Lenis scrolling
- GSAP entrance/reveal animations
- ScrollTrigger parallax + counters
- Infinite sponsor/topic marquee
- Magnetic CTA buttons
- 3D-style hover tilt cards
- Interactive FAQ accordion
- Responsive mobile navigation
- Speakers, agenda, stats, gallery, sponsors, testimonials, venue and CTA sections
- Black + light-green CyberFest visual system

Replace the sample remote images, sponsor names, dates, venue details and testimonials with official CyberFest assets/content before launch.
